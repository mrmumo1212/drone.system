# drone.system

kod python 3.12 sürüme göre yazılmıştır, doğrudan kullanılabilir.

AMACI: .waypoints formatında görev dosyasında istenilen noktaya rahatça 8 çizebilmek.

ÇALIŞMA MANTIĞI: Giriş dosyasına kendi waypoint dosyanızı yükleyin, ardından çemberin ilk merkezi olan indexi seçin(index seçildikten sonra otomatik olarak index ve index+1 waypointleri çemberin merkezleri kabul edilir),yarıçap değerini girin,tur başına nokta sayısını girin, ilk çemberden dönüş yönünü seçin,tur sayısını seçin ve ardından çıkış dosyasının (eğer hazırda dosya varsa üzerine yazar yoksa yeni bir dosyayı aynı dizine oluşturur) yolunu girin. Bundan sonra yapmanız gereken tek şey çalıştırmak.
